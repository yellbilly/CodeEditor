# Informativa sulla privacy – Code Editor

Code Editor non raccoglie, trasmette né condivide alcun dato personale.

- L'app non richiede permessi e non ha accesso a Internet.
- I file vengono aperti e salvati solo tramite il selettore file di Android, nelle posizioni che scegli tu.
- Le schede aperte e il testo non salvato sono conservati in locale, nella memoria privata dell'app, solo per ripristinare la sessione; vengono eliminati disinstallando l'app.
- Non sono presenti pubblicità, statistiche d'uso né servizi di terzi.
